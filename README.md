# VPS VPN Setup: Mieru + Hysteria 2 + Cloudflare WARP

Автоматический скрипт для настройки личного VPN-сервера на Ubuntu 22.04 / 24.04 с поддержкой современных, устойчивых к блокировкам протоколов и сплит-маршрутизацией исходящего трафика через Cloudflare WARP.

Скрипт разработан с упором на идемпотентность, безопасность и автоматическую оптимизацию сетевого стека под параметры сервера.

## 🚀 Возможности

1. **Автоматическая оптимизация сети:** вычисление буферов сокетов (`sysctl`) под ваш объем оперативной памяти и ядер CPU, включение TCP BBR + `fq` qdisc, TCP Fast Open и MTU Probing.
2. **Безопасность:** настройка `ufw` (закрыты все входящие порты, кроме SSH и сгенерированных VPN-портов), отключение ответов на ICMP (ping) на уровне ядра и iptables.
3. **Mieru (mita):** установка устойчивого к DPI (ГСП) протокола без использования TLS (шифрование XChaCha20-Poly1305 с защитой от активного зондирования).
4. **Hysteria 2:** установка QUIC-протокола с включенной обфускацией `salamander` (маскировка UDP-пакетов под случайный шум) и самоподписанным сертификатом.
5. **Cloudflare WARP (wgcf):** регистрация и настройка WARP-клиента с **точечной маршрутизацией (Split-Tunneling)**. Через WARP идет только трафик VPN-сервисов (по системному UID). Трафик SSH и системных служб сервера идет напрямую через основной IP (вы не потеряете доступ к VPS).
6. **Готовые конфиги:** автоматическая генерация конфигураций и строк подключения (`hysteria2://`) с сохранением в `/root/vpn-setup-info.txt` для быстрого импорта в клиенты (Nekoray, v2rayN, Mihomo и т.д.).

## 📋 Требования

* **ОС:** Чистая установка Ubuntu 22.04 LTS или Ubuntu 24.04 LTS.
* **Права:** Запуск от имени `root`.
* **SSH-порт:** 22 (если у вас другой порт, его можно передать через переменную, см. ниже).

## ⚡️ Быстрый запуск

Подключитесь к вашему серверу через SSH и выполните команду:

```bash
curl -fsSL https://raw.githubusercontent.com/ВАШ_GITHUB_НИК/НАЗВАНИЕ_РЕПОЗИТОРИЯ/main/setup.sh -o setup.sh && sudo bash setup.sh
```

### Если у вас кастомный порт SSH (например, 2222):

Перед запуском укажите переменную `SSH_PORT`:

```bash
SSH_PORT=2222 sudo -E bash setup.sh
```

## 🛠 Ручная проверка компонентов после установки

### 1. Проверка WARP (Сплит-маршрутизация)
* Обычный запрос с сервера должен показывать прямой IP сервера:
  ```bash
  curl https://www.cloudflare.com/cdn-cgi/trace/ | grep warp
  # Ожидается: warp=off
  ```
* Запрос от имени сервиса VPN должен идти через WARP:
  ```bash
  sudo -u hysteria curl https://www.cloudflare.com/cdn-cgi/trace/ | grep warp
  # Ожидается: warp=on
  ```

### 2. Проверка статуса сервисов
* **Mieru (mita):** `mita status` или `systemctl status mita`
* **Hysteria 2:** `systemctl status hysteria-server`
* **WARP:** `wg show wgcf-warp`
